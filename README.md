# mac-setup

This is the first step of setting up my Macs. It is public only so that a new Mac can download it before any login.

The script gets a new Mac ready to clone my private dot-files repo, then hands over to that repo's `bootstrap.sh`. It needs a GitHub login with access to that repo, so it is not useful to anyone else as it is.

The copy here is made from `public/mac-setup/setup.sh` in the dot-files repo. The run line in that repo's README is pinned to one commit of this repo.
